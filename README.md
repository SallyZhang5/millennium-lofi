# 千禧年声音 · Millennium LoFi（VST3 插件版）

把混音轨道上的声音实时变成千禧年前后的低保真味道。这是插件版本，插在 DAW
（比如 FL Studio）的混音轨道上，一边播放一边听变化，不需要导入导出。

## 现在这个版本能做什么

- 插在混音轨道上实时处理：磁带抖晃 → 过载 → 磁带频宽 → 底噪/嗡声 →
  降位深与降采样 → 编码器频带限制 → 塑料小喇叭 → 房间空间感
- 7 个工厂预设（千禧 MP3 随身听、磁带随身听、老式收音机、早期手机彩铃、
  8-bit 游戏机、电脑塑料小音箱、轻处理）
- 14 个可被 DAW 自动化的参数 + 旁通 + 干湿比
- 保存自己的预设（存在 `%APPDATA%\Millennium LoFi\Presets`，纯文本，
  可以备份、可以拷给别人），也能用 DAW 自带的预设菜单保存
- 复古 XP（Luna）风格界面，字体使用宋体

### 还没做的部分

**真实 MP3 编码环节目前用的是"频带限制近似"**：它按码率把高频切掉并做立体声收窄，
听感方向对，但还不是"真的用 64 kbps 压缩一遍再解回来"。真实编码器需要把 LAME
一起编译进来，作为下一步单独处理（涉及延时补偿，会在界面上标明）。

## 怎么编译（云端，不需要装编译器）

仓库里带了 GitHub Actions 工作流，push 之后自动编译：

1. 打开仓库的 **Actions** 标签
2. 等 `build-vst3` 变成绿色对勾（第一次约 8~12 分钟，要下载 JUCE）
3. 点进这次运行，在页面底部 **Artifacts** 里下载 `MillenniumLoFi-vst3`
4. 解压得到 `Millennium LoFi.vst3` 文件夹，这就是插件

编译过程中会顺便跑一遍离线自检（用同一套 DSP 引擎渲染一段测试音频，检查是否有
异常样本、电平是否合法），并把渲染结果一起打包给你试听。

本地编译（如果以后装了 Visual Studio 的 C++ 工具链）：

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
```

## 怎么装进 FL Studio

1. 把 `Millennium LoFi.vst3` 文件夹放到任意位置，例如 `D:\VST3\`
2. FL Studio → **Options → Manage plugins**
3. **Plugin search paths → Add path**，选中 `D:\VST3`
4. 点 **Start scan**（建议勾上 Verify plugins）
5. 在混音轨道点一个插入槽，搜索 `Millennium LoFi`

如果第一次扫不到，重启 FL 再扫一次。

安装不需要管理员权限，也不需要安装程序——放到哪个文件夹都行，删掉就是卸载。

## 参数说明

| 参数 | 作用 |
|---|---|
| 颗粒感（位深） | 越低越粗糙，16 位等于不处理 |
| 数码采样率 | 越低越闷、越有早期数码味 |
| 磁带高频衰减 | 模拟磁带吃掉的高频 |
| 磁带抖晃 | 走带不稳造成的音高飘动 |
| 过载失真 | 磁饱和与被推爆的输入级 |
| 底噪嘶声 | 磁带本底噪声，-90 dB 等于关闭 |
| 电流嗡声 | 电源干扰的低频嗡声 |
| MP3 码率 | 编码器频带限制的强度（当前为近似模式） |
| 低音削减 | 小喇叭放不出来的低频 |
| 小喇叭高频 | 塑料喇叭的高频上限 |
| 喇叭共鸣 | 塑料箱体在中频的嗡嗡共鸣 |
| 空间混响 | 房间大小 |
| 立体声宽度 | 0 是单声道 |
| 输出音量 | 总输出微调 |
| 干湿比 | 处理声与原始声的混合 |
| 旁通 | 临时关掉效果对比 |

## 代码结构

```
Source/dsp/LoFiEngine.h     音频引擎（纯 C++，不依赖 JUCE，可独立编译测试）
Source/dsp/DspUtils.h       滤波器、延迟线、混响、噪声等基础组件
Source/Parameters.h         参数定义与 7 个工厂预设
Source/PresetManager.h      用户预设的保存 / 读取 / 删除
Source/PluginProcessor.*    VST3 处理器（实时音频线程）
Source/PluginEditor.*       XP 风格界面
Source/XpLookAndFeel.h      XP 外观：滑杆、按钮、分组框、勾选框
Test/render_test.cpp        离线渲染与自检工具（CI 会跑）
```

引擎和界面是分开的：`Source/dsp` 里没有任何 JUCE 依赖，所以同一份代码既能编进
插件，也能编成命令行工具，用它和最早的 Python 版本做客观对比（音色指标差异）。

## 已知取舍

- **不归一化**：离线版本会把整首曲子归一到 -1 dBFS，插件无法预知未来，所以
  不做归一化，改用"输出音量"微调 + 0.9 以上才开始工作的安全软限幅
- **混响是实时算法**（施罗德结构）而不是离线版的卷积混响，二者听感接近但
  不会是逐采样相同
- **滤波器是有相位失真的 IIR**，离线版用的是零相位 FFT 滤波；幅频特性对齐，
  相位特性不同（这一点上插件更接近真实硬件的表现）
